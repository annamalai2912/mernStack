# React & JSX - Day 1 Practice Workspace

Repository for students to record their notes, basic terminologies, practical programs, and hands-on exercises.

## Directory Structure
Every module folder contains:
- `notes/`: `notes.md` containing basic terminologies of React and JSX.
- `programs/`: runnable source code and practical files practiced during the session.
- `exercises/`: hands-on challenge tasks and exercises to code and solve.

### Topics (6-Hour Day 1 Curriculum)
- `01-introduction-to-react-and-spa/` (`notes/`, `programs/`, `exercises/`)
- `02-react-vs-traditional-web-development/` (`notes/`, `programs/`, `exercises/`)
- `03-nodejs-and-npm-setup/` (`notes/`, `programs/`, `exercises/`)
- `04-vite-project-creation/` (`notes/`, `programs/`, `exercises/`)
- `05-understanding-project-structure/` (`notes/`, `programs/`, `exercises/`)
- `06-jsx-syntax-and-expressions/` (`notes/`, `programs/`, `exercises/`)
- `07-functional-components/` (`notes/`, `programs/`, `exercises/`)
- `08-component-rendering/` (`notes/`, `programs/`, `exercises/`)
- `09-practical-student-profile-dashboard/` (`notes/`, `programs/`, `exercises/`)
- `10-placement-focus/` (`notes/`, `programs/`, `exercises/`)

## How to Use
1. Clone this repository: `git clone <REPO_URL>`
2. Fill in your notes & terminologies in each module's `notes/notes.md`.
3. Practice and run code in `programs/`.
4. Solve the hands-on coding challenges in `exercises/`.
