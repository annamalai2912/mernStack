Repository for students to record their notes, basic terminologies, and practical programs.

- `04-vite-project-creation/`: `notes/` & `programs/`
- `05-understanding-project-structure/`: `notes/` & `programs/`

- `09-practical-student-profile-dashboard/`: `notes/` & `programs/`
- `10-placement-focus/`: `notes/` & `programs/`

## How to Use
1. Clone this repository: `git clone <REPO_URL>`
2. Open each topic folder.
3. Fill in the basic terminologies in `notes/notes.md`.
4. Code and run your practical programs inside `programs/`.
