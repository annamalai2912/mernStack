## 📌 Basic Terminologies

### 1. JSX (JavaScript XML)
- **Definition:** 
- **Can browsers read JSX directly?** (No - requires compilation)
- **What JSX compiles into:** (`React.createElement()`)

### 2. Curly Braces `{}` in JSX
- **Purpose:** (Evaluate any valid JavaScript expression inside JSX)
- **What can be put inside `{}`:** (Variables, arithmetic, ternary operators, function calls)
- **What CANNOT be put inside `{}`:** (Statements like `if/else`, `for`, `while`)

### 3. React Fragment (`<> ... </>`)
- **Definition:** 
- **Why we use it:** (Group multiple elements without adding extra nodes to the Real DOM)

### 4. `className` vs `class`
- **Why `className` is used:** (Because `class` is a reserved keyword in JavaScript)

### 5. `htmlFor` vs `for`
- **Why `htmlFor` is used:** (Because `for` is a reserved loop keyword in JavaScript)

### 6. Inline Styles in JSX
- **Syntax:** (`style={{ property: 'value' }}`)
- **Naming convention:** (`camelCase`, e.g. `backgroundColor`, `fontSize`)

### 7. Conditional Rendering in JSX
- **Ternary Operator:** (`condition ? <ComponentA /> : <ComponentB />`)
- **Logical AND (`&&`):** (`condition && <Component />`)
