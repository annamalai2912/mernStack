# Exercise: Add a New View

### Tasks:
1. Open `../programs/spa-demo.html`.
2. Add a new button: `<button onclick="showGrades()">Grades</button>`.
3. In the `<script>` section, create the `showGrades()` function to update `#root` with:
   `"<h3>Grades View</h3><p>CGPA: 8.5</p>"`.
4. Double-click `spa-demo.html` in your browser to verify that the view changes smoothly without a page reload.
