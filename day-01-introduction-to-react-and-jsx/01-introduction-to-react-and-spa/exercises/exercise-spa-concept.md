# Exercise: SPA Architecture & Navigation Simulation

### Task Description:
1. Open `../programs/spa-demo-practice.js`.
2. Add a new view named `grades` to the `views` object:
   ```javascript
   grades: "<h1>Student Semester Grades</h1><p>CGPA: 8.9 | Sem 5: 9.1</p>"
   ```
3. Add a simulated navigation button in your code that triggers `navigateTo('grades')`.
4. Inspect the browser console:
   - Does the page refresh?
   - How does this differ from traditional anchor tag `<a href="grades.html">` navigation?
5. Write your observations in `../notes/notes.md`.
