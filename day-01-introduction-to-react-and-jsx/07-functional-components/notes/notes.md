- **The LEGO Brick analogy:** (Small reusable pieces combined into full UI)

### 2. Functional Component
- **Definition:** (A plain JavaScript function that returns JSX)
- **Why modern React uses Functional Components instead of Class Components:** 

### 3. PascalCase Naming Convention
- **Rule:** (Component names MUST start with an uppercase letter, e.g. `StudentCard`, not `studentCard`)
- **Why React enforces this:** (To differentiate between built-in HTML tags and custom components)

### 4. Component Return Value
- **What a component must return:** (Valid JSX, null, or a Fragment)

### 5. Default Export vs Named Export
- **Default Export (`export default`):** (Only one per file, imported without `{}`)
- **Named Export (`export const` / `export function`):** (Multiple per file, imported with `{}`)

### 6. Component Reusability
- **Definition:** (Using the same component multiple times with different data)
