# Placement Exercise: 60-Second Mock Interview Drill

Set a 60-second timer for each question and practice answering out loud without pausing:

1. **Question 1:** "Why did your team decide to use React instead of Vanilla JavaScript?"
   - *Key keywords to include:* Declarative, Virtual DOM, Component reusability, State-driven.

2. **Question 2:** "What is an SPA and what happens when a user clicks a link?"
   - *Key keywords to include:* Client-side routing, single HTML file, JSON API fetch, no full page reload.

3. **Question 3:** "Can you explain how Virtual DOM and Reconciliation work?"
   - *Key keywords to include:* In-memory object, Diffing algorithm, $O(n)$ heuristic, minimal real DOM batch update.

4. **Question 4:** "Why is the `key` prop mandatory when using `.map()` to render lists in React?"
   - *Key keywords to include:* Identity of elements, diffing optimization, avoid index as key for dynamic lists.

5. **Question 5:** "What is JSX and what does it compile to?"
   - *Key keywords to include:* JavaScript XML, syntactic sugar, transpiled by Babel/esbuild into `React.createElement()`.
