# Placement Focus: Quick Interview Practice

Practice explaining these 3 core questions:

1. **Why do we use React instead of Vanilla JavaScript?**
   - React is declarative and manages DOM updates automatically using the Virtual DOM, so developers don't have to write tedious `document.getElementById` calls.

2. **What is JSX?**
   - JSX is a syntax extension that lets you write HTML-like elements inside JavaScript. Behind the scenes, it transpiles into pure JavaScript (`React.createElement`).

3. **Why is the `key` prop required when rendering lists?**
   - The `key` helps React uniquely identify which items in a list were changed, added, or removed, allowing fast and efficient DOM updates.
