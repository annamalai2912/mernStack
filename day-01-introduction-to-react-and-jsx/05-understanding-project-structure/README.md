# 📌 Module 05: Understanding Project Structure

## 🎯 Learning Objectives
By the end of this module, you should be able to:
1. Explain the role of every file and directory generated by Vite.
2. Trace the execution flow from `index.html` to `main.jsx` to `App.jsx`.
3. Understand `ReactDOM.createRoot()` and root mounting.
4. Know where to place assets, styles, and custom components.

---

## 📖 Key Concepts

### 1. Vite React Project Anatomy
```text
my-react-app/
├── index.html           # The single HTML entry point of the SPA
├── package.json         # Project metadata, scripts, and dependencies
├── vite.config.js       # Vite build configuration (React plugin setup)
├── public/              # Static files served directly without processing (e.g. favicon)
└── src/                 # Application source code (where 95% of your work happens)
    ├── main.jsx         # JavaScript entry point (mounts React into DOM)
    ├── App.jsx          # Root component of your application
    ├── App.css          # Styles scoped to App component
    ├── index.css        # Global CSS styles applied to the entire page
    └── assets/          # Static assets processed and bundled by Vite (images, svg)
```

### 2. Execution Flow: How React Mounts
```text
Browser requests page
       │
       ▼
1. index.html loads: contains <div id="root"></div> and <script type="module" src="/src/main.jsx">
       │
       ▼
2. main.jsx executes:
   - Imports React and ReactDOM
   - Finds <div id="root"> using document.getElementById('root')
   - Creates a React Root: ReactDOM.createRoot(...)
   - Renders <App /> inside <React.StrictMode>
       │
       ▼
3. App.jsx executes:
   - Evaluates functional component
   - Returns JSX
       │
       ▼
4. React compiles JSX into Virtual DOM and mounts Real DOM into <div id="root">
```

### 3. Key Files Breakdown
- **`index.html`**: Unlike Webpack/CRA where `index.html` is in `public/`, in Vite `index.html` is in the root directory because Vite treats it as an entry point.
- **`src/main.jsx`**:
  ```jsx
  import React from 'react';
  import ReactDOM from 'react-dom/client';
  import App from './App.jsx';
  import './index.css';

  ReactDOM.createRoot(document.getElementById('root')).render(
    <React.StrictMode>
      <App />
    </React.StrictMode>
  );
  ```
- **`<React.StrictMode>`**: A development-only tool that highlights potential problems, warns about deprecated methods, and runs components twice in dev mode to catch side effects.
