# Exercise: Node.js & npm Package Management

Tasks to complete in your terminal:
1. Test Node.js execution:
   Command: node ../programs/node-demo.js

2. Initialize a test project in a temporary folder:
   Command: npm init -y

3. Install 'canvas-confetti' as a regular production dependency:
   Command: npm install canvas-confetti

4. Install 'vite' as a development dependency:
   Command: npm install -D vite

5. Open 'package.json' and verify:
   - Is 'canvas-confetti' listed under "dependencies"?
   - Is 'vite' listed under "devDependencies"?
   - What version numbers are recorded?

6. Clean up: Delete node_modules and run `npm install`. Notice how npm restores all dependencies!
