# Exercise: npm Package Management Challenge

Tasks to complete in your terminal:
1. Initialize a test project in a temporary folder:
   Command: npm init -y

2. Install 'canvas-confetti' as a regular production dependency:
   Command: npm install canvas-confetti

3. Install 'vite' as a development dependency:
   Command: npm install -D vite

4. Open 'package.json' and verify:
   - Is 'canvas-confetti' listed under "dependencies"?
   - Is 'vite' listed under "devDependencies"?
   - What version numbers are recorded?

5. Inspect 'package-lock.json' and count how many sub-packages were resolved.

6. Clean up: Delete node_modules and run `npm install`. Notice how fast npm restores all dependencies from package-lock.json!
