## 📌 Dashboard Planning & Terminologies

### 1. Project Goal
- Build a modular **Student Profile Dashboard** using React functional components.

### 2. Component Hierarchy Plan
- Root Component: `App.jsx`
  - Child 1: `Header.jsx` (Institution name, student portal title)
  - Child 2: `ProfileCard.jsx` (Avatar, Name, Roll No, Department)
  - Child 3: `AcademicStats.jsx` (CGPA, Attendance %, Semester)
  - Child 4: `SkillsList.jsx` (Dynamically rendered badges using `.map()`)
  - Child 5: `ContactCard.jsx` (Email, Phone, GitHub, LinkedIn links)

### 3. Key Concepts Practiced in this Dashboard
- Functional components
- Component composition (nesting)
- JSX expressions (`{}`)
- Dynamic list rendering (`.map()` with `key`)
- Conditional styling (e.g. attendance badge color)
