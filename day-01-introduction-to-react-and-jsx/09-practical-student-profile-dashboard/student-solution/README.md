# 💻 Student Solution Folder

This is **your dedicated workspace** for the Day 1 practical assignment!

### Instructions:
1. Open terminal inside this folder:
   ```bash
   cd "day-01-introduction-to-react-and-jsx/09-practical-student-profile-dashboard/student-solution"
   ```
2. Initialize your Vite React application:
   ```bash
   npm create vite@latest . -- --template react
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Build your components and assemble your Student Profile Dashboard.
5. Launch and test your app:
   ```bash
   npm run dev
   ```
6. Commit your solution to Git!
