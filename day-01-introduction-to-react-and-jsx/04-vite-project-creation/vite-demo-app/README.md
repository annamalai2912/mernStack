# 🧪 Sandbox: Vite Demo App

This directory is an empty sandbox folder where students can practice initializing their very first Vite application!

### Hands-on Exercise:
1. Open terminal inside this folder:
   ```bash
   cd "day-01-introduction-to-react-and-jsx/04-vite-project-creation/vite-demo-app"
   ```
2. Run:
   ```bash
   npm create vite@latest . -- --template react
   ```
   *(Note: The dot `.` creates the files directly in the current directory).*
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start your server:
   ```bash
   npm run dev
   ```
5. Test modifying `src/App.jsx` by changing the text inside `<h1>` to `"Hello Mohammed Sathak!"`.
6. Notice the instant Hot Module Reload in the browser without full page reload!
